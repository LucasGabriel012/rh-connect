# apps/api

Futura API do RH Connect.

A API sera criada com Node.js, TypeScript, NestJS, Prisma, OpenAPI / Swagger UI, Jest e Supertest conforme o contexto tecnico vigente.

Nesta etapa, nenhum scaffold funcional de Back-end foi criado, nenhuma dependencia foi instalada, nenhum banco foi conectado e nenhuma migration foi gerada.
